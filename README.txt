Gottaprintem site bundle

Files in this zip:
- index.html (static multi-section landing page)
- /assets/ (logo SVGs, favicon, og image)
- App.jsx (React + Tailwind single-file component)

How to use:
- For a static site: deploy index.html and the /assets folder to any static host (Netlify, Vercel, GitHub Pages).
- For a React app: copy App.jsx into your React project, ensure Tailwind CSS is configured, and import it into your app.

Replace placeholders (email, shop link, gallery images) with your real content.
